# 🚀 React Counter App

A simple and beginner-friendly Counter Application built using **React.js**. This project helps you understand the fundamentals of React such as components, state management, and event handling.

---

## 📌 Features

* ➕ Increment the counter
* ➖ Decrement the counter
* 🔄 Reset the counter to zero
* ⚡ Instant UI updates using React state
* 🎯 Clean and minimal user interface

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Styling:** Tailwind CSS (optional)
* **Tooling:** Vite

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

### 1️⃣ Clone the repository

```
git clone https://github.com/Hackingish/Counter.git
```

### 2️⃣ Navigate to project folder

```
cd counter-app
```

### 3️⃣ Install dependencies

```
npm install
```

### 4️⃣ Run the development server

```
npm run dev
```

---

## 🧠 How It Works

* The app uses the `useState` hook from React to manage the counter value.
* Button clicks trigger functions that update the state.
* React automatically re-renders the UI when the state changes.
